# Contributing

Thanks for helping! All changes go through a pull request that the maintainer reviews. Nobody pushes directly to `main`.

1. Fork the repo and create a branch from `main`.
2. Make a focused change. Run `./gradlew :app:testDebugUnitTest`.
3. For UI changes, attach a screenshot (1920x1080 if you can).
4. Open a PR and fill in the template.

## Content rules

- Background photos: historic mosques and the Kaaba, no recognisable faces, with source + licence added to `assets/bg/CREDITS.txt`. Max 3840x2160 (no 8K).
- Quran, hadith and dua text must cite a source. Arabic changes should be proofread.
- Keep the UI RTL-correct and usable with a D-pad only.
